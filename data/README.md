# 实测数据

## 2026-10-30 基线（GPIO3，12 dB，64 次过采样，20 Hz）

条件：ESP32-C3 SuperMini，MAC `AA:BB:CC:DD:EE:FF`，103（10 kΩ）多圈电位器抽头接 GPIO3（丝印 3），
万用表真值 1603 mV；`100 nF` 未加（用户确认）。

关键结果：
- 原始码均值 2178.35；校准 1617.1 mV；线性 1755.4 mV；两者差 **−138.4 mV**。
- 万用表真值 **1603 mV**：校准误差 **+14.1 mV（0.88%）**，线性误差 **+152.4 mV（9.51%）**。
- D 行窗内峰峰值：均值 31.9 码（25.7 mV），最大 112 码；σ 均值 5.57 码（4.49 mV）。
- 高速抓取：峰峰 130 码（104.8 mV），σ 5.97 码（4.81 mV）。
- 50 Hz 幅度 **0.095 mV**、100 Hz **0.063 mV**：未发现工频拾取。
- 结论：首轮“0 V 却跳 100~300 码、峰峰 830 码”未复现；当前噪声以宽带+偶发尖峰为主。
- 291 点结论（0.1~2.7 V，230 点）：校准 max/RMS = **28.0 / 10.8 mV**，
  线性 = **328.5 / 159.4 mV**；校准 RMS 约为线性的 1/15。
- 12 dB 档位约 **2.89 V** 饱和（raw 4095，校准钳在 2940 mV），实际可用上限约 2.87 V。
- 全量程含饱和的极值不能用于线性度结论；报告已自动排除 raw ≥ 4090 的点。
- **加 100 nF 后**：1.65 V 处 σ 从 30.8 mV 降到 **1.05 mV**，峰峰从 250 mV 降到 **7.3 mV**；
  Wi-Fi 压测时 σ 升到 **1.79 mV**（+70%），绝对增量 <1 mV。
- **100 nF 下 0.1~2.7 V（24 点）**：校准 max/RMS = **12.6 / 6.73 mV**，
  线性 = **306.0 / 162.6 mV**；两点修正后 max/RMS = 5.53 / 3.12 mV。
- 用户导出的 33 点中有 2 点真值（3000/3300 mV）与 raw≈0 不符，已作为异常点排除；
  详见 `20261030_sweep33_100nF_points.csv` 与 `docs/04` 坑 7。
