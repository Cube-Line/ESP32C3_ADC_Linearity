# 02 - 硬件与引脚分析

> 依据：ESP32-C3 数据手册 / ESP-IDF v5.5.4 ADC 驱动、用户实测。

## 1. 芯片与开发板
| 项目 | 内容 |
|---|---|
| 芯片 | ESP32-C3（RISC-V 单核，160 MHz） |
| 模块/板 | ESP32-C3 SuperMini |
| ADC | ADC1：GPIO0~GPIO4（通道 0~4）；ADC2：GPIO5（通道 0） |
| 分辨率 | 12 bit |
| 连接 | 板载 USB-C → 芯片原生 USB Serial/JTAG |

> 注意：ESP32-C3 只有 ADC1 的 5 个通道常用；ADC2 仅 GPIO5 一路。

## 2. 引脚/资源分配
| 功能 | 引脚 | SuperMini 丝印 | 外设 | 配置 |
|---|---|---|---|---|
| ADC 输入 | GPIO3 | 3 | ADC1_CH3 | 12 dB 衰减，12 bit |
| 电位器高端 | 3V3 | 3V3 | 板载 LDO 输出 | 3.3 V【估】 |
| 电位器低端 | GND | G | 地 | 0 V |
| 日志/数据 | USB D-/D+ | USB-C | USB Serial/JTAG | 115200-8-N-1 |

### 2.1 可切换的 ADC1 通道（固件 `C` 命令）
| 通道 | GPIO | SuperMini 丝印 | 备注 |
|---|---|---|---|
| ADC1_CH0 | GPIO0 | 0 | 可用于交叉验证 |
| ADC1_CH1 | GPIO1 | 1 | 可用于交叉验证 |
| ADC1_CH2 | GPIO2 | 2 | 上电 strapping，避免外部强拉 |
| ADC1_CH3 | GPIO3 | 3 | **默认**，非 strapping |
| ADC1_CH4 | GPIO4 | 4 | 板载 LED（部分批次），注意负载 |

> C3 的 ADC2 只有 GPIO5 一路，本实验不使用；固件 `C` 命令仅允许 0~4。
> 交叉验证引脚时先断开电位器抽头，避免把 3.3 V 加到其他外设上。

## 3. 接线
```
        3V3 ──┬──────────────┐
              │              │
            ┌─┴─┐            │
            │   │ 多圈电位器  │
            │   │ 103 / 10 kΩ │
            └─┬─┘            │
              │ 抽头          │
              ├──────────────┼──► GPIO3 (丝印 3)
              │              │
             === 100 nF【建议】│
              │              │
        GND ──┴──────────────┘
```
- 电位器两端接 **3V3 / GND**，抽头接 **GPIO3**。
- 强烈建议抽头对 GND 并联 **100 nF**（靠近板子引脚），降低采样保持时的源阻抗与噪声。
- 输入电压严禁超过 3.3 V。

## 4. 关键分析
1. **源阻抗**：使用 **103（10 kΩ）** 精密多圈电位器；中点时源阻抗最高约 2.5 kΩ【估】。C3 ADC 采样保持电容很小，
   但高阻源 + 长杜邦线容易拾取工频干扰，表现为大幅跳码。加 100 nF 后源阻抗在采样瞬间由电容提供。
2. **衰减档位**：12 dB 标称约 0~3.3 V，但 2026-10-30 实测 **约 2.89 V 已饱和**
   （raw=4095，校准值钳在 2940 mV），实际可用上限约 **2.87 V**。
   要测 3.3 V 必须外部 **1:2 分压**，不能直接接 GPIO3。
3. **校准**：C3 支持 curve fitting 校准，eFuse 内保存出厂校准参数；校准只修正 ADC 自身，
   不修正外部电路（分压比、电源纹波）。
4. **ADC2/GPIO5**：本实验不用。
5. **strapping**：GPIO2/8/9 为上电 strapping，GPIO3 不涉及，适合做模拟输入。

## 5. 电源
- 板载 USB 5 V → 3V3 LDO；电位器直接由 3V3 供电。
- 若 3V3 轨本身有纹波，会直接叠加到输入电压上，属于“真值”的一部分，万用表读数可消除其影响。
