# 00 - 项目目标

## 1. 项目名称
ESP32-C3 ADC 线性度探究（校准值 vs 原始码线性换算）

## 2. 最终目标
在同一颗 ESP32-C3、同一路 ADC、同一组输入电压下，对比：
1. **ESP-IDF 校准**：`adc_cali_create_scheme_curve_fitting()` + `adc_cali_raw_to_voltage()`
2. **直接线性换算**：`raw / 4095 × 3300 mV`

用外部 103（10 kΩ）多圈精密电位器提供 0~3.3 V 输入，用万用表读数为真值，量化两种方式的
绝对误差、增益误差、非线性（INL）与噪声。

## 3. 规格指标
| 项目 | 目标 | 来源 |
|---|---|---|
| ADC 分辨率 | 12 bit（0~4095） | 【保】C3 数据手册 |
| 衰减 | 12 dB，量程约 0~3.3 V | 【保】ESP-IDF ADC 文档 |
| 过采样 | 每点可配置 1~256 次取均值（默认 64） | 【估】降噪 |
| 输出速率 | 20 Hz（50 ms，可配置 10~5000 ms） | 【估】兼顾实时与串口带宽 |
| 串口 | 115200-8-N-1，USB Serial/JTAG | 【保】板载 USB |
| 输入源 | 多圈电位器 3V3/GND 分压 | 用户接线 |
| 真值 | 万用表逐点读数 | 用户方案 |

## 5. 技术约束
- 芯片固定 ESP32-C3（只有 ADC1：GPIO0~GPIO4；ADC2 仅 GPIO5）。
- 开发框架 ESP-IDF v5.5.x（本机 v5.5.5），目标 `esp32c3`。
- 板子通过 USB-C 原生 USB Serial/JTAG 连接（WSL 下为 `/dev/ttyACM0`）。
- 电位器由板载 3V3 供电，输入不得超过 3.3 V。

## 6. 非目标（本期不做）
- 多通道 / ADC2 / DMA 连续采样
- 低功耗、深度睡眠
- 温度漂移长期实验（可作为后续）
- PCB / 外壳设计

## 7. 关键决策记录（ADR 摘要）
| 决策 | 结论 | 原因 |
|---|---|---|
| ADC 引脚 | GPIO3（ADC1_CH3，丝印「3」） | 非 strapping，SuperMini 上通常空闲 |
| 真值来源 | 万用表手动输入 | 比电位器刻度换算可信，直接得到 Vin |
| 上位机技术栈 | Python + tkinter + matplotlib | 无需额外 GUI 框架，绘图/交互够用 |
| 串口控制台 | USB Serial/JTAG | SuperMini 板载 USB-C 直连芯片 |
| 衰减/位宽 | 12 dB / 12 bit | 覆盖 0~3.3 V，分辨率最高 |
| 校准方案 | curve fitting（C3 仅支持此方案） | 【保】ESP-IDF C3 校准能力 |
| 运行时配置 | 串口命令 C/A/N/P | 避免为换引脚/衰减/过采样反复烧录 |
| 噪声诊断 | `B` 高速抓取 + 上位机 FFT | 20 Hz 输出会混叠，无法直接看到 50 Hz |
| 统计核心 | 纯 Python 模块 `host/adc_core.py` | GUI 与 CLI 复用、可脱离硬件单测 |
| 结果归档 | Markdown + PNG（GUI/CLI） | 结论可复现、可入库 |
| Wi-Fi 干扰实验 | STA 连接 指定 Wi-Fi + 主机 UDP 广播 | 路由器客户端隔离时单播不通 |
