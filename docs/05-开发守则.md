# 05 - 开发守则

## 1. 工程与工具
- ESP-IDF 固定 **v5.5.x**：`source ~/.espressif/v5.5.5/esp-idf/export.sh`。
- 目标芯片：`esp32c3`；串口默认 `/dev/ttyACM0`（USB Serial/JTAG）。
- 上位机 Python 3.11+（本机 3.14），依赖在工程内 `.venv`，不污染系统环境。
- 算法层 `host/adc_core.py` 不依赖 tkinter，提交前跑
  `python -m unittest host/test_core.py`。
- 不提交 `build/`、`.venv/`、`sdkconfig`（见 `.gitignore`）。

## 2. 代码风格
- 固件：ESP-IDF 风格（4 空格、`snake_case`、错误码用 `ESP_ERROR_CHECK`）。
- Python：PEP 8，类型标注，GUI 逻辑与串口线程分离（线程只往 `queue` 放数据）。
- 注释、文档、提交信息使用中文；变量/函数名使用英文。

## 3. 实时性约定
- 采集周期 50 ms（20 Hz），单次 64 点过采样（均可运行时配置）。
- GUI 主线程只做解析/绘图，串口读取在独立线程。
- 绘图刷新上限约 5 Hz，避免 Tk 事件循环被 matplotlib 拖死。
- 固件配置变更由命令任务置位，主循环在采样间隙应用；禁止两处并发操作 ADC。

## 4. 文档规范
- 需求/决策先落 `docs/01`，方向性决策进 `00` 的 ADR。
- 每个阶段完成更新 `03`；踩坑进 `04`；引脚/接线变更回写 `02`。
- 数值标注 **【保】**（器件保证）或 **【估】**（设计目标/实测估计）。

## 5. 安全与可靠性
- ADC 输入不得超过 3.3 V，禁止负压。
- 电位器由板载 3V3 供电，接线前先断电。
- 烧录/串口占用同一 USB 设备，GUI 与 `idf.py monitor` 不能同时打开。
- WSL 下 USB 需 `usbipd` 转发；串口权限依赖 `dialout/plugdev` 组。
- USB Serial/JTAG 命令任务必须处理“未连接 EOF”，不能因一次 `fgets` 返回 NULL 就退出。
- 上位机打开 USB Serial/JTAG 后释放 `DTR/RTS`；串口读取用块读 + 拆行，避免逐行读拖慢抓取。
