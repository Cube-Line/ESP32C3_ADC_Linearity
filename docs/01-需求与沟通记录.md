## 沟通 #1 — 2026-10-30 初始需求

**用户原文：**
> 我们来基于ESP32C3Supermini和espidf探究一下ESP32的ADC线性度，我在外部接一个多圈精密电阻来输入电压，你用串口获取并绘图，使用python直接绘制GUI，我们来采集一些点看看ESP32C3的ADC在使用校准程序和直接使用之间的差异

**理解：**
- 硬件：ESP32-C3 SuperMini，外部 103（10 kΩ）多圈精密电位器给 ADC 提供可变电压。
- 固件：ESP-IDF，输出 ADC 原始值与校准换算值。
- 上位机：Python GUI，串口读取并实时绘图。
- 目的：对比「使用 IDF 校准程序」和「直接使用（原始码线性换算）」的差异与线性度。

**决策（结构化提问确认）：**
| 问题 | 用户选择 | 落地 |
|---|---|---|
| ADC 接哪个脚 | GPIO3（ADC1_CH3） | 固件 `ADC_CHANNEL_3` |
| 真值参考 | 万用表读电压，GUI 手动输入 | GUI 标定点输入框 |
| 电位器接法 | 两端 3V3/GND，抽头接 ADC | 0~3.3 V 全量程 |

## 沟通 #5 — 2026-10-30 提交 291 点全量程数据

**用户原文：**
> 我已经采集了291个数据点,你看看

**理解：**
- 对 291 点（31.2~3313 mV）做误差、拟合、INL 与饱和区分析，给出最终结论。
- 数据来自 GUI 导出（CSV + 会话 JSON），保存在桌面。

**决策：**
| 决策 | 结论 | 原因 |
|---|---|---|
| 饱和点处理 | raw ≥ 4090 自动排除，单独统计 | 36 点已饱和，会主导 max/INL |
| 结论范围 | 以 0.1~2.7 V 为主，附 0.1~2.8 V 与全可用范围 | 2.7 V 内校准 max ≤28 mV |
| 数据归档 | CSV/JSON/报告/PNG 全部入 `data/` | 结果可复现 |
| 量程建议 | 3.3 V 必须外部 1:2 分压 | 12 dB 实测约 2.89 V 饱和 |
| 噪声 | 本批 σ≈31 码（25 mV），高于基线 | 建议加 100 nF 后复测 |

**结论：**
- 0.1~2.7 V：校准 max/RMS = 28.0/10.8 mV；线性 = 328.5/159.4 mV。
- 校准 RMS 约为线性的 1/15；线性换算偏大 +7%~+12%。
- 详细结论见 [09-实验结论与建议](09-实验结论与建议.md)。

## 沟通 #6 — 2026-10-30 Wi-Fi 持续收发实验

**用户原文：**
> 使用 <SSID> <密码>（凭据已隐去）

**理解：**
- ESP32 以 STA 连接 指定 Wi-Fi，持续发送/接收，再采集 ADC 点观察 Wi-Fi 干扰。
- 电脑与 ESP32 在同一 指定 Wi-Fi 网络，用 UDP 广播压测。

**决策：**
| 决策 | 结论 | 原因 |
|---|---|---|
| Wi-Fi 模式 | STA 连接 指定 Wi-Fi | 用户给定 SSID/密码 |
| 负载方式 | 主机 UDP 广播 + ESP32 回传 | 路由器客户端隔离时单播不通 |
| 控制方式 | GUI 按钮 / `W 1\|0\|s` | 采点时可随时 A/B |
| 凭据存放 | 暂时硬编码在 `main/adc_linearity.c` | 私有仓库；公开前需移到 Kconfig/secret |
