## 2. 校准 vs 线性（291 点全量程实测）

条件：GPIO3 / 12 dB / 64 次过采样 / 20 Hz；真值为万用表逐点读数；100 nF 未加。
数据：[20261030_sweep291_points.csv](../data/20261030_sweep291_points.csv)，
报告：[20261030_sweep291_points_report.md](../data/20261030_sweep291_points_report.md)。

### 2.1 可用范围 0.1~2.7 V（230 点）
| 指标 | ESP-IDF 校准 | 原始码线性 | 说明 |
|---|---:|---:|---|
| max\|error\| | **28.0 mV** | **328.5 mV** | 相对万用表真值 |
| RMS 误差 | **10.8 mV** | **159.4 mV** | |
| 平均误差 | +7.2 mV | +131.3 mV | |
| 拟合斜率 | 1.0097 | 1.1177 | 理想 1 |
| 拟合截距 | -6.2 mV | -30.0 mV | 理想 0 |
| INL | **12.4 mV（0.48%）** | **41.7 mV（1.61%）** | 拟合残差最大值 |

### 2.2 不同可用上限
| 范围 | 点数 | 校准 max / RMS | 线性 max / RMS |
|---|---:|---:|---:|
| 0.1~2.6 V | 220 | 24.4 / 9.7 mV | 297.4 / 148.4 mV |
| 0.1~2.7 V | 230 | **28.0 / 10.8 mV** | **328.5 / 159.4 mV** |
| 0.1~2.8 V | 239 | 40.0 / 12.7 mV | 365.0 / 170.7 mV |
| 0.03~2.87 V（raw<4090） | 255 | 54.4 / 15.2 mV | 409.1 / 179.4 mV |

> 结论：校准 RMS 约为线性的 **1/15**（10.8 vs 159.4 mV），max 误差约 **1/12**。
> 原始码线性换算在 0.5~2.5 V 区间偏大 **+7%~+12%**，不能直接当电压用。

### 2.4 100 nF 复测（2026-10-30，31 点，推荐结果）

条件：同上，抽头对 GND 加 **100 nF**；31 点原始扫描（真值 138.5~3315 mV），
其中 5 点饱和、2 点异常（输错单位/位置）已排除，**26 个可用点**。

| 范围 | 点数 | 校准 max / RMS | 线性 max / RMS | 校准 INL |
|---|---:|---:|---:|---:|
| 0.1~2.7 V | 24 | **12.6 / 6.73 mV** | **306.0 / 162.6 mV** | 5.56 mV |
| 0.1~2.8 V | 25 | 20.3 / 7.74 mV | 336.0 / 172.9 mV | 7.19 mV |
| 0.14~2.87 V | 26 | 40.8 / 11.03 mV | 390.3 / 186.0 mV | 23.11 mV |

- 0.1~2.7 V：校准斜率 1.0068、截距 -6.87 mV；线性斜率 1.1159、截距 -33.60 mV。
- 在 IDF 校准上再加两点 gain/offset 修正：max **5.53 mV**、RMS **3.12 mV**。
- 窗内 σ 约 1.6~3.9 码（1.3~3.1 mV），比 291 点扫描（σ≈31 码）干净得多。
- 数据/报告：[24 点 CSV](../data/20261030_sweep24_100nF_0p1-2p7.csv)、
  [报告](../data/20261030_sweep24_100nF_0p1-2p7_report.md)。

> 2.1 的 291 点数据未加 100 nF，噪声抬高了 RMS（10.8 mV）；加 100 nF 后 RMS 降到 6.7 mV。
> 精度结论建议以 2.4 为准。

## 3. 噪声（2026-10-30 首轮，异常状态）
| 项目 | 值 | 备注 |
|---|---|---|
| 输入直流 | ≈0 V（万用表） | 抽头在低端 |
| 原始码均值 | 约 155 / 263 交替 | 约 10 Hz 摆动 |
| 单窗口峰峰值 | 最高 830 码（≈669 mV） | **异常，疑似悬空/高阻** |
| 校准 − 线性 | −20.2 ~ +8.1 mV | 同一批异常数据 |

> 上述噪声数据仅用于定位接线问题，不能作为 ADC 性能结论。

### 3.1 噪声诊断指标口径（v2）
| 指标 | 定义 | 用途 |
|---|---|---|
| 峰峰值 pp | 单窗口 `raw_max − raw_min`（码 / mV） | 直观噪声幅度，稳定判据用 |
| σ | 单窗口原始码标准差（码 / mV） | 与 pp 互补，抗偶发尖峰 |
| 主频 | 高速抓取幅度谱最大值（抛物线插值） | 判断 50 Hz 工频/其他周期干扰 |
| 单频幅度 | 指定频率最小二乘正弦拟合（mV） | 准确读出 50/100 Hz 幅度，不受栅栏效应影响 |
| 等效 fs | `n / total_us` | 频谱横轴与可测上限 |

- 20 Hz 采样对 50 Hz 的混叠频率为 `|50 − 2×20| = 10 Hz`，与首轮观测一致。
- `B 4096` 在几十 kHz 等效采样率下可直接分辨 50/100 Hz；分辨率约 `fs/n`。
- 【测】2026-10-30 基线：50 Hz 0.095 mV、100 Hz 0.063 mV（无工频拾取）；
  未加 100 nF 时窗内 σ 约 31 码（25 mV）。加 100 nF 后的对比仍待做。

### 3.2 2026-10-30 上板基线（首轮异常未复现）
条件：GPIO3 / 12 dB / 64 次 / 20 Hz；万用表真值 1603 mV；100 nF 未加。

| 指标 | 值 | 来源 |
|---|---|---|
| 原始码均值 | 2178.35 | 【测】6 s / 120 点 |
| ESP-IDF 校准 | 1617.1 mV | 【测】 |
| 原始码线性 (×3300/4095) | 1755.4 mV | 【测】 |
| 校准 − 线性 | **−138.4 mV** | 【测】 |
| 万用表真值 | 1603 mV | 【测】用户读数 |
| 校准误差 | **+14.1 mV（+0.88%）** | 【测】 |
| 线性误差 | **+152.4 mV（+9.51%）** | 【测】 |
| 窗内峰峰值 | 均值 31.9 码（25.7 mV），最大 112 码 | 【测】 |
| 窗内 σ | 均值 5.57 码（4.49 mV），最大 10.83 码 | 【测】 |
| 高速抓取 | 8192 点 @ 7415.6 Hz，1.10 s | 【测】`B 8192` |
| 高速抓取峰峰 / σ | 130 码（104.8 mV） / 5.97 码（4.81 mV） | 【测】 |
| 50 Hz / 100 Hz 幅度 | 0.095 mV / 0.063 mV | 【测】无明显工频 |
| 偶发尖峰 | 约 0.1% 样本，最高 +75 / −55 码 | 【测】 |

**解读**
- 首轮“0 V 却 100~300 码、峰峰 830 码”未复现，工频拾取不是当前主因。
- 当前噪声由宽带噪声 + 稀疏尖峰组成；加 100 nF 前后需各抓一次对比。
- 万用表真值 1603 mV：**ESP-IDF 校准误差 +14.1 mV（0.88%），原始码线性误差 +152.4 mV（9.51%）**。
  在当前点校准明显更接近真值；“raw×3300/4095”不能直接当电压用。
- 数据文件：[data/](../data/README.md)。

> 上述为单点、单次上电数据；已能说明该点的换算误差量级，但全量程结论仍需 ≥10 点。

### 3.4 Wi-Fi 开/关 A/B（有 100 nF，真值 1.650 V）
| 场景 | raw 均值 | 校准 | 峰峰值均值 | σ（码 / mV） |
|---|---:|---:|---:|---:|
| Wi-Fi 关 | 2252.9 | 1671.9 mV | 7.3 mV | 1.30 / **1.05 mV** |
| Wi-Fi 开 + 广播压测 | 2251.6 | 1670.6 mV | 14.0 mV | 2.22 / **1.79 mV** |

- 压测约 210 pps / 2.4 Mb/s 双向；
- Wi-Fi 使 σ 增加约 **70%**（1.05 → 1.79 mV），峰峰值约翻倍；
- 绝对增量 <1 mV，对 0.1~2.7 V 测量影响很小。
- 数据：[data/20261030_100nF_summary.md](../data/20261030_100nF_summary.md)。

### 3.5 精度结论
- 1.650 V 时校准 1671.9 mV，系统误差 **+21.9 mV**；
- 噪声降到 1~2 mV 后，**误差主要由 IDF 校准残余决定**；
- 0.1~2.7 V：IDF 校准 RMS 10.8 mV / max 28 mV；两点修正可到约 3 mV 级；
- 实际可用分辨率：单窗口约 1 mV，0.5 s 平均可到亚 mV（受校准/温漂限制）。
