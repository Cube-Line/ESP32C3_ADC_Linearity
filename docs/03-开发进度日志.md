## 2026-10-30 — 第三轮：上板复测与命令修复

**做了什么**
- 确认 `/dev/ttyACM0` 为 ESP32-C3（MAC `AA:BB:CC:DD:EE:FF`，4 MB Flash），
  原固件是 MAX6675 温度 + WiFi；先整片读取 4 MB 备份（`backup/`，不入库），再烧录本工程。
- 上板发现并修复 USB Serial/JTAG 命令问题：
  - `fgets(stdin)` 在主机未连接时返回 NULL，命令任务启动即退出 → 改为 `fgetc` + EOF 重试。
  - GUI 打开串口后 `DTR/RTS=False`；串口读取改为块读 + 拆行，抓取 4096 行由约 25 s 降到 <1 s。
- 验证：`H` / `S` / `B 8192` 全部正常；GUI 实机连接并抓取 2048 点成功。
- 采集基线数据：
  - 6 s / 120 点：raw 2178.35，cal 1617.1 mV，lin 1755.4 mV（差 −138.4 mV）。
  - 窗内峰峰均值 31.9 码，σ 均值 5.57 码。
  - `B 8192`：7415.6 Hz、1.10 s；峰峰 130 码，σ 5.97 码；50 Hz 仅 0.095 mV。

  - 万用表真值 1603 mV：校准 +14.1 mV（0.88%），线性 +152.4 mV（9.51%）。

**结论**
- 首轮异常（0 V 时 100~300 码、峰峰 830 码）未复现；当前无明显工频拾取。
- 当前噪声为宽带 + 约 0.1% 偶发尖峰。
- **当前点 ESP-IDF 校准远优于原始码线性换算**（误差 0.88% vs 9.51%）；
  全量程是否同样成立，需继续补点。

**下一步**
1. 加 100 nF 前后各抓一次 `B 8192`，对比 σ/峰峰/50 Hz。
2. 完成 ≥10 点全量程标定，导出 CSV/报告，回写 08 与最终结论。
3. 视结果决定是否测试不同衰减档位/多次上电重复性。

## 2026-10-30 — 第五轮：291 点全量程标定与结论

**做了什么**
- 接收 GUI 导出的 291 点标定数据（31.2~3313 mV），归档到 `data/`。
- 分析脚本增加饱和点自动识别与排除（raw ≥ 4090），报告同时给出
  “可用范围”和“含饱和全量程”两组统计。
- 生成完整报告与配图：`data/20261030_sweep291_points_report.md/.png`。

**结果（0.1~2.7 V，230 点）**
| 指标 | 校准 | 线性 |
|---|---:|---:|
| max\|e\| | **28.0 mV** | **328.5 mV** |
| RMS | **10.8 mV** | **159.4 mV** |
| 斜率 / 截距 | 1.0097 / -6.2 mV | 1.1177 / -30.0 mV |
| INL | 12.4 mV（0.48%） | 41.7 mV（1.61%） |

- 校准 RMS 约为线性的 **1/15**，max 约为 **1/12**；线性换算在 0.5~2.5 V 偏大 +7%~+12%。
- **12 dB 在约 2.89 V 饱和**：36 点 raw≥4090，校准钳在 2940 mV；实际可用上限约 2.87 V，
  不能覆盖 3.3 V，需外部 1:2 分压。
- 本批窗内 σ 约 31 码（25 mV），明显高于基线 5.6 码；可能与采点调整、接线/上位机负载有关，
  需加 100 nF 后复测确认。

**结论**
- 项目核心问题已有答案：**用 curve fitting 校准，不要用 raw×3300/4095**；量程上限约 2.87 V。
- 最终结论与建议见 [09-实验结论与建议](09-实验结论与建议.md)。

**下一步**
1. 加 100 nF，重采 20~30 点，确认噪声与误差能否进一步下降。
2. 做 1:2 分压，验证 0~3.3 V 覆盖。
3. 可选：不同衰减档位、多次上电重复性。

## 2026-10-30 — 第七轮：100 nF 与 Wi-Fi 干扰实测

**做了什么**
- 抽头对 GND 加 100 nF 后复测（真值 1.650 V，12 s / 241 点）。
- 做 Wi-Fi 关 / 开+广播压测 A/B。
- 保存 D 行与 B 8192 数据到 `data/`。

**结果**
| 指标 | 无 100 nF | 有 100 nF |
|---|---:|---:|
| σ（窗内） | 30.76 mV | **1.05 mV** |
| 峰峰值（均值） | 249.7 mV | **7.3 mV** |
| 单窗口 ENOB | 6.5 bit | **11.4 bit** |

- Wi-Fi 开 + 压测时：σ 1.05 → **1.79 mV**（+70%），峰峰值 7.3 → 14.0 mV；
- 绝对增量 <1 mV；1.650 V 处校准误差 +21.9 mV，已由校准系统误差主导。

**结论**
- 100 nF 是噪声问题的关键，加后噪声降约 30 倍。
- Wi-Fi 干扰存在但很小（<1 mV），对常规电压测量可接受。
- 下一步：用 100 nF 重采 20~30 点，确认校准残余；需要 <10 mV 精度时加两点修正。

| max\|e\| | **12.6 mV** | **306.0 mV** |
