# ESP32C3_ADC_Linearity — 开发文档

用 ESP32-C3 SuperMini + ESP-IDF 探究片内 ADC 的线性度：
**ESP-IDF 校准曲线（curve fitting）** vs **原始码直接线性换算（raw×3300/4095）**。

- 工程位置：`ESP32C3_ADC_Linearity`
- 硬件：ESP32-C3 SuperMini + 103（10 kΩ）多圈精密电位器（3V3/GND 分压，抽头接 GPIO3）
- 固件：ESP-IDF v5.5.x，USB Serial/JTAG 输出 CSV，支持运行时切换通道/衰减/过采样与高速抓取
- 上位机：Python 3.11+ + tkinter + matplotlib，实时绘图/稳定判据/多点平均/标定点/误差统计/
  会话保存/CSV 与 Markdown 报告导出
- 离线分析：`host/analyze.py`，对导出的 CSV 生成报告与配图

## 一句话摘要
用同一颗 C3 的同一路 ADC，同时输出「校准 mV」和「原始码线性 mV」，用万用表逐点做真值，
量化两者在 0~3.3 V 上的误差、斜率与 INL；并用高速抓取 + FFT 解释异常噪声来源。
