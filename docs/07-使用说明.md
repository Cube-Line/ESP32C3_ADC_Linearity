# 07 - 使用说明

> 固件 v2 / 上位机 v2。除常规标定外，新增稳定判据、平均、会话、报告与噪声频谱。

## 1. 硬件接线
```
3V3 ── 103（10 kΩ）电位器固定端 A
GND ── 103（10 kΩ）电位器固定端 B
GPIO3（丝印 3）── 103 电位器抽头（滑臂）
GPIO3 ──||── GND      （100 nF，强烈建议）
```
- 输入范围 0~3.3 V，禁止超压。
- 用 USB-C 连接板子与电脑（原生 USB Serial/JTAG）。
- 排查时可改接 GPIO0/1/2/4，固件用 `C` 命令切换通道。

## 2. 编译
```bash
source ~/.espressif/v5.5.5/esp-idf/export.sh
cd ESP32C3_ADC_Linearity
idf.py set-target esp32c3      # 首次
idf.py build
```

## 3. 烧录
```bash
idf.py -p /dev/ttyACM0 flash
```
WSL 下若没有 `/dev/ttyACM0`，先用 `usbipd` 把 USB 设备转发进 WSL：
```powershell
usbipd list
usbipd bind --busid <BUSID>
usbipd attach --wsl --busid <BUSID>
```

## 4. 串口检查与命令
```bash
python3 - <<'PY'
import serial, time
s = serial.Serial('/dev/ttyACM0', 115200, timeout=1)
s.write(b'H\n')          # 命令帮助
s.write(b'S\n')          # 当前配置
for _ in range(8):
    print(s.readline().decode(errors='replace').strip())
PY
```
正常应看到 20 Hz 的 `D,...` 行，以及 `#CFG` / `#HELP` 行。

固件命令：

| 命令 | 示例 | 说明 |
|---|---|---|
| `S` | `S` | 打印当前配置 |
| `C` | `C 1` | 切到 GPIO1 / ADC1_CH1 |
| `A` | `A 6` | 6 dB 衰减 |
| `N` | `N 128` | 128 次过采样 |
| `P` | `P 100` | 100 ms 周期 |
| `B` | `B 4096` | 抓 4096 个原始码 |
| `W` | `W 1` / `W 0` / `W s` | Wi-Fi 负载开 / 关 / 查状态 |

> `idf.py monitor` 与 GUI 不能同时占用串口。

## 6. 标定采集步骤
1. 连接串口，确认「采样率」约 20 Hz、曲线随电位器变化。
2. 把电位器转到目标位置，输入万用表真值（`1.234` 表示 V，`1234` 表示 mV）。
3. 保持「等待稳定后记录」勾选（默认阈值 50 mV 峰峰，连续 3 次；超时 4 s 仍会记录，等待中再按 F2 可立即记录）。
4. 点「记录当前点」或按 `F2`。程序会等待并取最近 N 点平均（默认 10 点）。
5. 重复 2~4，覆盖 0.1 V、0.5 V、1.0 V … 2.8 V，至少 10 点。
   > 12 dB 档约 **2.89 V 饱和**；3.0~3.3 V 的点 raw 会固定在 4095，
   > 不能用于线性度统计。要测 3.3 V 先做 1:2 分压。
6. 看「统计」中的误差/RMS/斜率/INL；点「导出 CSV」或「导出报告」。

> 读数一直不稳时，先看峰峰值/σ，并做下一节的频谱诊断；也可临时取消“等待稳定”。

## 7. 噪声频谱诊断（F9）
1. 连接串口后按 `F9`（或点「噪声频谱」）。
2. GUI 自动发送 `B 4096`，弹出窗口显示波形、幅度谱、主频、50/100 Hz 幅度。
3. 判读：
   - 主频在 50 Hz、50 Hz 幅度明显 → 工频拾取（高阻/长线/缺 100 nF）。
   - 频谱平坦但峰峰大 → 接触不良、电源纹波或板级问题。
   - 短接抽头到 GND 仍跳 → 重点怀疑引脚/板子。
4. 加 100 nF 后重抓，比较 50 Hz 幅度是否下降。
5. 「导出 CSV」保存原始码与摘要，便于复盘。

## 8. Wi-Fi 负载干扰实验
固件可连接指定 Wi-Fi（在本地 `main/wifi_secrets.h` 配置 `WIFI_SSID/WIFI_PASS`，该文件不入库），
用持续 UDP 广播压测 Wi-Fi，观察射频/电源噪声对 ADC 的影响。

1. GUI 连接后点「Wi-Fi 负载」按钮（或串口发 `W 1`）；
2. 等约 5~10 s，按钮会显示 ESP32 的 IP 与 tx/rx 计数；
3. 电脑连接同一个 Wi-Fi 网络，运行：
   ```bash
   .venv/bin/python host/wifi_load.py
   ```
   脚本会自动找 `wl*` 接口和网段广播地址，持续双向广播（约 2~3 Mb/s）；
4. 此时正常采点；采完再点一次按钮关闭，做「Wi-Fi 开/关」A/B 对比；
5. 若路由器开了客户端隔离，单播会不通，脚本默认用**广播**，仍能双向收发。

命令：`W 1` 开、`W 0` 关、`W s` 查状态。`#WIFI` 行包含 `ip/gw/tx/rx`。
> 该实验用于观察 Wi-Fi 对 ADC 噪声的影响，不改变 ADC 本身配置。

## 9. 会话与报告
- **自动保存**：GUI 每记录一个点就写入 `data/autosave_session.json`；
  异常关闭/切串口后重新启动会提示恢复，避免丢点。
- 「保存会话」：把标定点、配置、频谱摘要另存为 JSON（`.json`）。
- 「载入会话」：恢复上次标定点，继续补测。
- 「导出报告」：生成 Markdown + PNG（测量值-真值、误差-真值两张图）。
- 「导出 CSV」：逐点原始码/σ/真值/两种换算/误差/平均点数 + 配置元数据。

## 10. 命令行逐点标定（sweep.py）
没有桌面或想快速采点时，用命令行向导（同样支持稳定判据 + 多点平均）：

```bash
.venv/bin/python host/sweep.py --port /dev/ttyACM0
# 可选：--n 20 每点平均 20 行；--stable-mv 50 稳定阈值（默认 50，超时仍记录）；--out data/points.csv
```

- 输入万用表电压（`1.234` 表示 V，`1234` 表示 mV）回车 → 等待稳定后记录。
- 空回车 → 刷新当前读数；`u` → 撤销上一个点；`q` → 结束。
- 每记录一点就写一次 CSV；结束时自动生成 `_report.md` 与 `_report.png`。
- 默认输出到 `data/points_<时间>.csv`。

## 13. 常见问题
| 现象 | 排查 |
|---|---|
| 找不到串口 | WSL 未转发 USB；检查 `usbipd list` / `lsusb` |
| 打开串口被占用 | 关闭 `idf.py monitor` 或其他串口工具 |
| 数据不变化 | 检查抽头是否接 GPIO3、电位器是否供电 |
| 读数大幅乱跳 | 抽头高阻/悬空，或缺少 100 nF；按 F9 看 50 Hz 幅度 |
| 命令无响应 | 确认固件为 v2（含 EOF 修复）；上位机需释放 DTR/RTS；串口终端按行发送并带回车 |
| 抓取很慢/超时 | 上位机需块读；`B 8192` 正常约 1~2 s，超过 10 s 说明在逐行读或固件未响应 |
| 曲线到 2.9 V 附近变平 | 12 dB 档位已饱和（raw=4095）；3.3 V 需 1:2 分压 |
| 等待稳定总是超时 | 阈值太小或噪声大；先做频谱诊断 |
| 显示中文方框 | 安装中文字体（如 Sarasa Gothic / 文泉驿） |
| 报告配图中文方框 | 同上，matplotlib 需要中文字体 |

## 14. 默认参数
| 参数 | 值 |
|---|---|
| 通道 | ADC1_CH3 / GPIO3 |
| 衰减 | 12 dB |
| 位宽 | 12 bit |
| 过采样 | 64（1~256 可调） |
| 周期 | 50 ms（10~5000 可调） |
| 波特率 | 115200 |
| 线性换算满量程 | 3300 mV / 4095 |
| 稳定阈值 | 50 mV 峰峰，连续 3 次；超时仍记录（无 100 nF 时的默认值） |
| 标定点平均 | 10 点 |
