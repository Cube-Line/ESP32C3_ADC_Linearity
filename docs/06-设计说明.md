# 06 - 设计说明（系统架构）

> v2（2026-10-30）：增加运行时命令、σ 统计、稳定判据、频谱诊断与报告导出。

## 1. 系统分层架构
```
┌──────────────┐   0~3.3V   ┌──────────────────────────────────┐
│ 103 多圈电位器 │───────────►│ ESP32-C3 SuperMini               │
│ 3V3/GND 分压  │  GPIO0~4   │  ADC1 单通道（默认 GPIO3）        │
└──────────────┘            │  ├─ N 次过采样 → raw / min/max/σ │
                            │  ├─ curve fitting 校准 → mV      │
                            │  ├─ 运行时命令 C/A/N/P/B         │
                            │  └─ USB Serial/JTAG 115200       │
                            └──────────────┬───────────────────┘
                                           │ CSV 行 + B 行
                            ┌──────────────▼───────────────────┐
                            │ host/gui.py                      │
                            │  串口线程 → queue → Tk 主线程     │
                            │  实时绘图 / 稳定记录 / 频谱      │
                            │  会话 JSON / CSV / 报告          │
                            └──────────────┬───────────────────┘
                                           │ CSV
                            ┌──────────────▼───────────────────┐
                            │ host/analyze.py                  │
                            │  统计 / Markdown / PNG           │
                            └──────────────────────────────────┘
```

## 2. 信号流
1. 电位器分压产生 Vin（0~3.3 V）。
2. 固件每 `period_ms` 连续读 N 次 ADC，求均值、min、max、σ。
3. 对均值/min/max 分别调用 `adc_cali_raw_to_voltage()`。
4. 输出一行 CSV（D 行）；GUI 解析后：
   - 实时画「校准 mV」「raw×3300/4095」随 raw 的散点；
   - 显示峰峰值与 σ，判断读数是否稳定；
   - 用户输入万用表真值后记录标定点（可等待稳定 + 最近 N 点平均）；
   - 计算两种方式的误差、拟合斜率/截距、INL；
   - 可一键抓取高速原始码并做 FFT。

## 4. 串口协议（v2）
```text
#FW,adc_linearity,2
#CFG,pin=GPIO3,chan=3,atten=12,width=12,n=64,period_ms=50,cali=1
#COL,t_ms,raw_x100,raw_min,raw_max,cal_mv,cal_min_mv,cal_max_mv,raw_std_x100
D,12345,204850,2040,2052,1649,1642,1655,35
#WIFI,state=1,mode=sta,ssid=指定 Wi-Fi,ip=192.168.1.100,gw=192.168.1.1,tx=123,rx=45
```
| 字段 | 含义 |
|---|---|
| `t_ms` | 上电后毫秒 |
| `raw_x100` | N 点均值 ×100（两位小数） |
| `raw_min/max` | 单次过采样窗口内原始码最小/最大 |
| `cal_mv` | 均值经 curve fitting 校准后的 mV；不可用时 -1 |
| `cal_min_mv/cal_max_mv` | min/max 对应的校准 mV |
| `raw_std_x100` | 窗口内标准差 σ ×100（v2 新增） |

### 4.1 运行时命令
| 命令 | 参数 | 作用 |
|---|---|---|
| `H` / `?` | — | 帮助 |
| `S` | — | 打印 `#CFG` |
| `C` | 0~4 | 切换 ADC1 通道/GPIO |
| `A` | 0/2/6/12 | 衰减 dB（2 表示 2.5 dB 档） |
| `N` | 1~256 | 过采样点数 |
| `P` | 10~5000 | 周期 ms |
| `B` | 16~8192，默认 1024 | 高速抓取原始码 |

命令任务只写 `pending` 配置/请求标志，主循环在两次采样之间应用并重建校准句柄，
避免与 ADC 采样并发。命令任务用 `fgetc` 逐字符组行；USB 未连接时读返回 EOF，
必须 `clearerr` 后延时重试，否则任务会在启动早期退出、命令永久无响应。

### 4.2 高速抓取（B 命令）
```text
#BURST_BEGIN,4096,0,3,12
B,0,2041
B,1,2043
...
#BURST_END,4096,139872
```
- 第 2 字段为点数，第 3 字段保留为 0，后两字段为通道/衰减。
- 主机用 `#BURST_END` 的总耗时计算等效采样率 `fs = n / total_us × 1e6`。
- 上位机必须“块读 + 按行拆分”；逐行 `readline` 会把 4096 行拖到约 25 s。
- `B 8192` 实测约 1.3 s 完成（等效 7.4 kHz，1.1 s 数据）。

## 4.3 Wi-Fi 负载（v2.1）
- STA 连接 `指定 Wi-Fi`，`WIFI_PS_NONE`、HT20，关闭省电以保证射频持续工作。
- 独立任务循环：向已学习的主机/广播地址发 1400 B UDP；收到非 53 端口包则回显；
  每 50 ms 向网关 53 发一次 DNS 查询，作为无主机时的 RX 兜底。
- 主机 `host/wifi_load.py` 默认向本机 `wl*` 网段广播地址发包，绕开客户端隔离；
  双向各约 2~3 Mb/s（实测 ~250 pps）。
- 串口每 5 s 输出 `#WIFI,state=...,ip=...,gw=...,tx=...,rx=...`。
- ADC 与 Wi-Fi 共用电源/射频，用于 A/B 噪声实验，不改变 ADC 配置。

## 5. 关键换算与统计
- 线性换算：`lin_mv = raw / 4095 × 3300`
- 单点误差：`err = measured_mv − true_mv`
- 拟合：`measured = a·true + b`（最小二乘）
- INL：拟合残差的最大绝对值（点数 ≥3 才计算）
- σ（固件）：`σ = sqrt(N·Σx² − (Σx)²) / N`，整数开方后 ×100 输出
- 标定点平均：取最近 N 个 D 行（校准值有效的）分别平均 raw/cal/lin/σ
- 稳定判据：连续 3 次窗口峰峰值 ≤ 阈值（默认 50 mV，无 100 nF 时）才记录；超时 4 s 仍记录，等待中再按 F2 立即记录

## 6. 采样、滤波与诊断
- N 次过采样均值把随机噪声降低约 √N 倍【估】。
- 硬件建议 100 nF 采样电容；软件暂无数字滤波（保留原始波动信息）。
- 20 Hz 输出对 50 Hz 工频会混叠到 10 Hz，因此不能用实时曲线直接判断干扰频率。
- `B` 抓取为背靠背 oneshot，等效 fs 通常为几十 kHz，足以看到 50/100 Hz。
- 频谱：去均值 + Hann 窗；主频用抛物线插值；单频幅度用最小二乘正弦拟合
  （避免 FFT 栅栏效应导致幅度低估）。
- 判据：50 Hz 幅度显著高于噪声底 → 工频拾取；频谱平坦但峰峰大 → 接触/电源/板级问题。

## 7. 报告
- GUI「导出报告」与 `host/analyze.py` 共用 `build_report_markdown()`。
- 内容：配置、真值范围、两种方式统计表（max|e|/RMS/平均误差/斜率/截距/INL）、
  逐点明细、自动结论、覆盖不足告警、噪声抓取摘要。
- 同时生成「测量值 vs 真值」与「误差 vs 真值」两幅图。

## 8. UI 布局
- 左：上「电压 vs raw」实时图；下「标定点误差」散点图。
- 右：串口、当前读数（含峰峰/σ）、标定点录入（平均点数/稳定阈值）、已记录点、
  统计、导出按钮。
- 频谱窗口：上波形、下幅度谱，顶部摘要与「重新抓取/导出 CSV」。
- 快捷键：`F2` 记录当前点，`F9` 高速抓取，`Enter` 在输入框内记录。
